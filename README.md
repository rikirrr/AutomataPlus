# Automata+
## Создано командой УММНУ

Automata+ — это утилита для автоматического создания Docker-контейнеров и запуска проектов по ссылке на GitHub или локальной директории. Написана на языке Python и не имеет никаких зависимостей.

### Как работает скрипт?
- Анализирует файлы проекта и ищет паттерны языков программирования и сборщиков.
- Определяет язык программирования и его версию.
- Подбирает соответствующий Docker-образ.
- Генерирует .bash скрипт, который устанавливает зависимости проекта и запускает его.

В результате вы получаете готовый Docker-контейнер, который уже запущен и работает.

### Поддерживаемые языки программирования

На данный момент реализована поддержка 4-х языков и популярных инструментов сборки:
- `Язык`	Инструменты сборки
- `Python`	pip, poetry, conda
- `Java / Kotlin`	gradle, maven
- `Go`	make, mage, taskfile

### Установка и запуск

Скрипт запускается через Python 3.x:

`python main.py [--languages] [--help] repo_or_path`

Параметры
Аргумент	Описание
`repo_or_path`	Ссылка на GitHub или путь к локальному проекту
`--languages`	Показать список поддерживаемых языков
`-h, --help`	Показать справку и выйти

### Примеры использования

Запуск проекта с GitHub:

`python main.py https://github.com/rikirrr/ExampleMainPy`


Запуск локального проекта (например, папка tests):

`python main.py ./tests/python/pure/`
